# TBI Motor Recovery

Traumatic Brain Injury (TBI) often leaves patients with lingering motor and cognitive deficits
- Many TBI patients experience impaired fine motor skills, limiting daily activities
- Traditional therapy is time-consuming, inconsistent, and often inaccessible outside clinics
- Lack of feedback makes it difficult for patients and clinicians to track improvement

TBI Motor Recovery addresses this by providing
- Structured, data‑driven motor drills that can be used early and consistently
- Personalized progression with measurable outcomes
- Accessiblity both at home and in clinic

Features
- Eye-tracking exercises
- Fine motor control exercises
- AI-informed recovery plans
- Data-driven performance metrics
